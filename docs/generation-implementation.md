# Generation implementation and activation

The production code includes a Stable Audio 2.5 adapter, durable PostgreSQL dispatch, cost reservations, MP3 decoding/duration/silence checks, SHA-256 integrity, private S3-compatible storage and published-only signed delivery. It has not made a real music-provider request. Test providers and synthetic audio occur only in the test suite.

The adapter uses the official synchronous `POST /v2beta/audio/stable-audio-2/text-to-audio` contract with multipart prompt, model, duration and MP3 output. The artist core is unchanged by the adapter. Include the instrumental instruction in each source core prompt. No audience names, email addresses or recordings are sent. There is no reference-audio upload or automatic provider/model substitution. Source: https://platform.stability.ai/docs/api-reference (retrieved October 11, 2026). Stable Audio 3 evaluation remains a later adapter change, not a silent upgrade.

Activation requires all of: `GENERATION_ENABLED=1`, project-specific provider/storage credentials, `GENERATION_RIGHTS_ACK=our-jam-public-downloads-approved`, approved integer per-request/per-event/lifetime budget amounts, target duration and a future `GENERATION_PRICE_VERIFIED_UNTIL`. The acknowledgement is deployment configuration recording the account owner's confirmation; code cannot establish legal permission. Current licensing guidance is at https://kb.stability.ai/knowledge-base/stable-audio-commerical-and-usage-licensing and remains subject to the applicable account terms.

Before dispatch, an artist lock serializes reservations and changes the unique round job to submitting. Reservations are conservative maximum estimates in cents, retained even after uncertainty. They limit submitted requests against the configured price estimate, not the provider's billing system. Verify that the configured amount covers actual current prices before enabling; expiration stops further dispatch. No new spending is authorized by implementation.

There is no automatic retry of a music POST. Network uncertainty, a crash, or interrupted processing produces UNKNOWN; inspect the provider record and retained attempt identity before deciding how to recover. Because this endpoint has no documented client idempotency or lookup contract, blind retry is deliberately unavailable. Storage SDK retries reuse the same deterministic object key and do not generate another song. A crash after upload but before metadata commit can leave a private orphan at the recorded attempt path; do not submit again to recover it.

Returned bytes are bounded to 32 MiB. FFprobe validates MP3 stream and expected duration; FFmpeg decodes and checks for silence. Validation does not prove artistic quality, absence of vocals, or rights clearance. Storage remains private, checks upload integrity and verifies stored length/metadata before committing a release. Public delivery requires published, unhidden releases. The authenticated owning artist can also obtain a short-lived preview for an unpublished, unhidden result through the separate operator route. Ensure the bucket is private and has no anonymous read policy before activation; this has not been tested against a real bucket.

Boundary release remains the default; immediate and artist-review policies can be selected for new rounds. Publication holds apply even at set end. See `docs/release-controls.md` for private review, explicit publication and unsent cancellation. Audio generation cannot finish at the same instant its last audience vote is submitted. Opt-in email fanout is implemented but disabled pending live sender acceptance; foreground clients receive publication updates, while push remains open.

Run a dedicated process with `npm run start:worker` on an approved always-on plan. For a small rehearsal, `RUN_INLINE_GENERATION=1` can process one job at a time in the web service. The single-service free Blueprint leaves generation disabled. Free-tier sleeping and deployments are not a live-show reliability guarantee. Benchmark actual latency and music quality with approved credits before a performance.
